# Документация проекта Kubiki

> **Kubiki** — современная, высокопроизводительная кроссплатформенная IDE для Kubernetes.  
> Полноценный аналог Lens/OpenLens/Freelens с архитектурой без Electron (на базе чистого Rust-движка `kubiki-core`), потребляющий минимум памяти и работающий полностью локально (serverless / local-first).

---

## Как передать проект на создание UI другому ИИ-агенту

Для запуска разработки UI автономным агентом передайте следующую инструкцию:

```markdown
Привет! Ты разрабатываешь интерфейс для проекта Kubiki.
Весь основной бэкенд-движок Kubernetes уже полностью готов, оттестирован и находится в папке `crates/kubiki-core`.

Изучи документацию:
- `./docs/06-UI-BUILD-PLAN.md` (главный документ: утверждённый план UI — дизайн-система, макет, спецификации экранов, фазы работ с чек-листами)
- `./docs/07-UI-PROGRESS.md` (живой журнал прогресса: что уже сделано и что в очереди — читай первым!)
- `./docs/05-HEADLESS-CORE-API.md` (API движка kubiki-core — что используешь через Tauri IPC)
- `./docs/02-ARCHITECTURE-AND-DESIGN.md` (общие требования к стилю JetBrains / VS Code)

Начинай с фазы UI-0 из плана. Существующий каркас в `src/` переписывай по спецификациям плана, не выбрасывая работающее.
Подключение к реальному кластеру валидируется через Tauri IPC начиная с фаз UI-1/UI-4 (test-кластер локальный).

После каждого завершённого рабочего блока обновляй `docs/07-UI-PROGRESS.md` (статусы по фазам, заметки, очередь).
```
