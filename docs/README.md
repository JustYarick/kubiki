# Документация Kubiki

Kubiki — разрабатываемая desktop IDE для Kubernetes на Tauri 2 / Rust / React. Текущая стадия — **early alpha / pre-MVP**.

Начинайте с [09 — фактическая стадия](09-PROJECT-STATUS.md), [08 — UX и технический аудит](08-UX-TECHNICAL-AUDIT.md) и актуального блока [07 — журнал прогресса](07-UI-PROGRESS.md).

Сервисы `kubiki-core` не означают автоматически работающие функции приложения: отдельно проверяются backend, IPC, UI и live-сценарий. Не переносите прежние утверждения «100% готово» в новые задачи без проверки.
